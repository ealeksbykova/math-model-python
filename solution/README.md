(каждая лабораторная — отдельный файл).

| Лабораторная | Файл | Тема |

| 1.1 | `Практическое занятие 1_1 - метод Либмана.ipynb` | Уравнение Лапласа. Метод Либмана, ускоренный метод Либмана |

## Содержание работ

### Практическое занятие 1.1 — метод Либмана

Краткая постановка задачи и дискретная модель (пятиточечный шаблон, метод Либмана —
он же Гаусс–Зейдель) с аналитическим решением $U = \\sin(\\pi y)\\,\\mathrm{sh}(\\pi(1-x))/\\mathrm{sh}\\,\\pi$;
далее в ноутбуке оставлены **только задания методички (№1, 2 и 3)**:

* **Задание 1** — метод Либмана для заданного числа итераций **и верификация** модели по
  тестовой одномерной задаче п. 1.2.3.2 (стенки $U(0,y)=100$, $U(1,y)=40$, адиабатические
  горизонтальные границы, 4×4 интервалов, 50 итераций): получается матрица
  `100 / 85 / 70 / 55 / 40`, совпадающая с эталонной программой `Lab1.java` и с точным
  решением $U = 100 - 60x$ с погрешностью $\sim 2\cdot10^{-4}$; выводятся таблица
  сравнения с аналитикой, поле решения и график сходимости по итерациям.
* **Задание 2** — модифицированная программа: число итераций для заданной точности
  $\\varepsilon$ (критерий $\\max|U^{(k+1)}-U^{(k)}| < \\varepsilon$) и график зависимости
  числа итераций от $\\varepsilon$; сверка с методичкой
  ($\\varepsilon = 10^{-3} \\Rightarrow 9$, $\\varepsilon = 10^{-4} \\Rightarrow 12$).
* **Задание 3** — ускоренный метод Либмана: зависимость числа итераций от коэффициента
  релаксации $\\omega$, оптимум $\\omega \\approx 1.2$ (ускорение в ~2 раза) и сравнение
  с обычным методом Либмана.

### Практическое занятие 1.2 — метод конечных разностей

* Вывод разностных производных из рядов Тейлора (2.4)–(2.9) с **численной проверкой порядка**:
  односторонние разности — $O(h)$, центральные — $O(h^2)$.
* Все пять этапов МКР: сетка → аппроксимация → подстановка → **СЛАУ** → решение.
* Матрица $A$ для сетки $4\times3$ выписана явно, проверено диагональное преобладание.
* Решение СЛАУ прямым методом и Гауссом–Зейделем, совпадение решений.
* Сравнение сходимости Якоби и Гаусса–Зейделя.
* Сходимость $O(h^2)$ при измельчении сетки; совпадение с методом Либмана до $10^{-11}$.

### Практическое занятие 2 — явная схема

* Явная схема для уравнения теплопроводности, показатель устойчивости $Fo = a\Delta t/\Delta x^2$.
* **Задание 1** — модель + верификация по аналитическому нестационарному решению (ряд Фурье);
  исследование сходимости по $\Delta x$ (порядок ≈ 2).
* **Задание 2** — устойчивость: подтверждён порог $Fo \le 0.5$; увеличение $\lambda$ в 10 раз
  ($Fo = 0.889$) приводит к расходимости.
* **Задание 3** — зависимость от временного шага ($m = 300$ и $m = 600$), первый порядок по $\Delta t$.
* **Задание 4** — ГУ третьего рода, все четыре варианта методички; стационарные значения
  совпадают с аналитикой до $10^{-12}$ °C; анализ времени релаксации $\tau = L^2/(\pi^2 a)$.

## Запуск

### Требования

Python 3.9+ и пакеты из `requirements.txt`:

```bash
python3 -m pip install -r requirements.txt
```

### Открыть ноутбуки

```bash
jupyter lab solution/        # или: jupyter notebook solution/
```

Каждый ноутбук автономен: первая ячейка сама находит пакет `labkit` (по текущему каталогу
или родительским), поэтому запускать можно как из `solution/`, так и из корня репозитория.

### Перезапустить ноутбуки (пересобрать выходные данные)

```bash
cd solution
python3 tools/notebooks/execute.py            # все три ноутбука
python3 tools/notebooks/execute.py lab1_1     # выборочно: lab1_1 | lab1_2 | lab2
```

Если нужно изменить содержание, правьте `tools/notebooks/build_*.py` и пересоберите ноутбук:

```bash
cd solution/tools/notebooks
python3 build_lab2.py                 # записывает ноутбук в solution/
python3 build_lab2.py /tmp/x.ipynb    # или в указанный путь
```

### Тесты

```bash
cd solution
python3 -m pytest -q                  # весь набор (включая сквозной перезапуск ноутбуков)
python3 -m pytest -m "not slow" -q    # только быстрые тесты (без исполнения ноутбуков)
```

## Замечания по методичке

При сверке результатов обнаружены две неточности в исходных указаниях; в ноутбуках они
разобраны отдельными пояснениями:

1. **Практическое занятие 2, таблица п. 2.2.6, вариант D.** В строке «стационарные значения
   (явная схема)» указано `144.05 / 99.46` — это значения варианта C, перенесённые по ошибке
   (у варианта D те же $\alpha$, но другие температуры среды). Аналитическая формула и расчёт
   дают `110.00 / 80.00`, что совпадает со строкой «аналитический расчёт» той же таблицы.

2. **Практическое занятие 2, п. 2.2.6, «стационар устанавливается на 0.70 с».** Значение
   $0.70$ с соответствует не полному выходу на стационар, а характерному времени релаксации
   $\tau = L^2/(\pi^2 a) \approx 0.76$ с: за это время отклонение убывает примерно в $e$ раз.
   Практически стационарный режим (отклонение < 0.5 °C) наступает лишь к $t \approx 4.4$ с.

Кроме того, значения числа итераций из п. 1.2.3.3 ($\varepsilon=10^{-3} \Rightarrow 9$,
$\varepsilon=10^{-4} \Rightarrow 12$) воспроизводятся **точно** при сетке 4×4 интервалов
(5×5 узлов) — в ноутбуке 1.1 это проверяется явно.
